من جرّب يومًا أن يكتب TEI XML بمساعد برمجة يعمل بالذكاء الاصطناعي، فلا بد أنه لاحظ كثرة عثراته: عناصر تظهر في غير موضعها، وسمات تُخترع اختراعًا، وقواعد تداخل تُطرح جانبًا. فللنموذج فكرة تقريبية عن هيئة TEI، أما معرفةٌ يُعتدّ بها بالمواصفة فلا.

وهذا ما يعالجه tei-mcp: يفتح لوكلاء الذكاء الاصطناعي بابًا مباشرًا، عبر الأدوات، إلى إرشادات TEI P5.

## ما MCP؟

[بروتوكول سياق النموذج (Model Context Protocol)](https://modelcontextprotocol.io)، أو MCP اختصارًا، معيار مفتوح يتيح لتطبيقات الذكاء الاصطناعي أن تتصل بمصادر بيانات وأدوات خارجية. تصوّروه منفذ USB للذكاء الاصطناعي: بروتوكول واحد يوصل أي عميل متوافق — Claude وCursor وWindsurf وسواها — بخدمات متخصصة.

ويتيح خادم MCP *أدوات* يستدعيها الذكاء الاصطناعي في أثناء المحادثة؛ فبدل أن يتكل النموذج على ما حفظه من بيانات التدريب، يستفتي مصدرًا حيًّا موثوقًا.

## ما الذي يصنعه tei-mcp

يحلّل tei-mcp مواصفة TEI P5 بصيغة ODD ويتيح 16 أداة تجيب عن أكثر ما يطرحه المحقّق أو المرمّز من أسئلة:

- **ما هذا العنصر؟** ابحثوا عن أي عنصر أو صنف أو ماكرو أو وحدة (module) بالاسم، بمطابقة لا تفرّق بين حالتي الأحرف، مع اقتراحات لتصويب الأخطاء الإملائية.
- **ما السمات التي يقبلها؟** حلّوا السمات عبر التسلسل الهرمي الكامل للأصناف — السمات المحلية أولًا، ثم الموروثة على ترتيبها.
- **ما الذي يجوز إدراجه داخله؟** ابسطوا نماذج المحتوى في أشجار مهيكلة، أو اطلبوا قائمة مسطّحة بالعناصر الأبناء الصالحة.
- **أيجوز وضع هذا العنصر هنا؟** تحققوا من تداخل الأصل والفرع، أو تتبّعوا إمكانية البلوغ عبر التسلسل الهرمي الكامل للعناصر.
- **هل وثيقتي صحيحة؟** تحققوا من ملف TEI XML وفق المواصفة: نماذج المحتوى، وقيم السمات، وقوائم القيم المغلقة، وسلامة الإحالات، وتحذيرات الإهمال (deprecation).
- **وماذا عن مخطط مشروعي؟** حمّلوا ملف تخصيص ODD ليُحصر كل ما سبق في المجموعة الفرعية من TEI الخاصة بمشروعكم.

## لماذا يهم هذا الأمر

الترميز بـTEI لا يستغني عن الرجوع الدائم إلى الإرشادات. فالمرمّز المتمرس يستبطن الأنماط الأكثر شيوعًا، لكنه يظل محتاجًا إلى مراجعة المواصفة عند العناصر الأقل ألفة أو نماذج المحتوى المعقدة. أما مساعدو الذكاء الاصطناعي، وليس لديهم شيء من هذه المعرفة المستبطنة، فالداء عندهم أشد: يهلوسون ترميزًا معقول المظهر باطل الجوهر.

مع tei-mcp لا يعود النموذج بحاجة إلى التخمين؛ إذ يستطيع أن يلتمس الجواب في المواصفة قبل أن يخطّ قوسًا زاويًّا واحدًا. والحصيلة ترميز مطابق لـTEI P5 — أو لتخصيص ODD الخاص بمشروعكم.

## للبدء

ثبّتوه من PyPI:

```bash
pip install tei-mcp
```

ثم أضيفوه إلى إعدادات عميل MCP لديكم:

```json
{
  "mcpServers": {
    "tei": {
      "command": "uvx",
      "args": ["tei-mcp"]
    }
  }
}
```

ينزّل الخادم مواصفة TEI عند أول تشغيل، ويعمل مع أي عميل متوافق مع MCP.

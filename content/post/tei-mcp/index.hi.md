अगर आपने कभी किसी एआई कोडिंग असिस्टेंट से TEI XML लिखवाया है, तो ग़ौर किया होगा कि वह 
गड़बड़ कर बैठता है। एलिमेंट वहाँ आ जाते हैं जहाँ उन्हें नहीं होना चाहिए। एट्रिब्यूट 
गढ़ लिए जाते हैं। नेस्टिंग के नियम अनदेखे रह जाते हैं। मॉडल को मोटा-मोटी अंदाज़ा है 
कि TEI कैसी दिखती है, पर विनिर्देश का कोई भरोसेमंद ज्ञान नहीं।

tei-mcp इसका हल है: यह एआई एजेंटों को TEI P5 दिशानिर्देशों तक सीधी, उपकरण-आधारित 
पहुँच देता है।

## MCP क्या है?

[Model Context Protocol](https://modelcontextprotocol.io) (MCP) एक खुला मानक है, जो 
एआई ऐप्लिकेशनों को बाहरी डेटा-स्रोतों और उपकरणों से जोड़ने देता है। इसे एआई का USB 
पोर्ट समझिए: एक ही प्रोटोकॉल, जिससे कोई भी संगत क्लाइंट – Claude, Cursor, Windsurf 
और अन्य – विशेष सेवाओं में प्लग हो सकता है।

एक MCP सर्वर ऐसे *उपकरण* उपलब्ध कराता है, जिन्हें एआई बातचीत के दौरान बुला सकता है। 
रटे हुए प्रशिक्षण-डेटा के भरोसे रहने के बजाय मॉडल किसी जीवंत, प्रामाणिक स्रोत से 
पूछ सकता है।

## tei-mcp क्या करता है

tei-mcp TEI P5 के ODD विनिर्देश को पार्स करता है और 16 उपकरण उपलब्ध कराता है, जो 
किसी संपादक या एनकोडर के सबसे आम सवालों का जवाब देते हैं:

- **यह एलिमेंट क्या है?** किसी भी एलिमेंट, क्लास, मैक्रो या मॉड्यूल को नाम से 
  खोजिए – बड़े-छोटे अक्षर का भेद किए बिना, और टाइपिंग की ग़लती पर सुझाव के साथ।
- **यह कौन-से एट्रिब्यूट लेता है?** पूरी क्लास-श्रेणी में एट्रिब्यूट का निर्धारण – 
  पहले स्थानीय, फिर क्रम से विरासत में मिले।
- **इसके भीतर क्या आ सकता है?** कंटेंट मॉडल को संरचित वृक्ष के रूप में खोलिए, 
  या वैध संतानों की सपाट सूची पाइए।
- **क्या यह एलिमेंट यहाँ आ सकता है?** अभिभावक-संतान नेस्टिंग की जाँच कीजिए, या 
  पूरी एलिमेंट-श्रेणी में पहुँच का पता लगाइए।
- **क्या मेरा दस्तावेज़ वैध है?** किसी TEI XML फ़ाइल को विनिर्देश पर परखिए: कंटेंट 
  मॉडल, एट्रिब्यूट के मान, बंद मान-सूचियाँ, संदर्भों की अखंडता और अप्रचलन की 
  चेतावनियाँ।
- **और मेरी परियोजना की स्कीमा?** ODD अनुकूलन फ़ाइल लोड कीजिए, ताकि ऊपर का सब कुछ 
  आपकी परियोजना के TEI उपसमुच्चय तक सीमित रहे।

## यह क्यों मायने रखता है

TEI एनकोडिंग में दिशानिर्देशों को बार-बार देखना पड़ता है। अनुभवी एनकोडर सबसे आम 
पैटर्न आत्मसात कर लेते हैं, लेकिन कम परिचित एलिमेंटों या जटिल कंटेंट मॉडलों के लिए 
उन्हें भी विनिर्देश खोलना पड़ता है। एआई असिस्टेंटों के पास ऐसा कोई आत्मसात ज्ञान 
नहीं होता, इसलिए उनकी समस्या और गंभीर है: वे देखने में ठीक-ठाक पर ग़लत मार्कअप 
गढ़ लेते हैं।

tei-mcp के साथ एआई को अनुमान लगाने की ज़रूरत नहीं। पहला कोण-कोष्ठक लिखने से पहले 
वह विनिर्देश में जवाब देख सकता है। नतीजा: ऐसा मार्कअप जो TEI P5 के – या आपकी 
परियोजना के ODD अनुकूलन के – अनुरूप हो।

## शुरुआत कैसे करें

PyPI से इंस्टॉल कीजिए:

```bash
pip install tei-mcp
```

फिर इसे अपने MCP क्लाइंट की कॉन्फ़िगरेशन में जोड़िए:

```json
{
  "mcpServers": {
    "tei": {
      "command": "uvx",
      "args": ["tei-mcp"]
    }
  }
}
```

सर्वर पहली बार चलने पर TEI विनिर्देश डाउनलोड करता है और किसी भी MCP-संगत क्लाइंट 
के साथ काम करता है।

[persNamer](/code/persnamer/)は、ささやかな便利ツールとして始まりました。VIAF番号を渡すと、TEIの`<person>`エントリと、テキストに注釈を付けるための`<persName>`タグが返ってきます。やることは一つだけで、生成されるエントリは薄いものでした――名前一つ、日付二つ、識別子一つ。本日リリースしたバージョン1.2は、やることを一つに保ったまま、そのエントリを取っておく価値のあるものにします。

## 人物エントリに今なにが入っているか

まずは名前から。VIAFのクラスターには参加図書館ごとに一つずつ名前が入っており、旧版のpersNamerは最初に出会ったラベルをそのまま取っていました。ヴォルテールを尋ねると、返ってくるのは「فولتير،」――アラビア語の形で、末尾のコンマ付き――おまけに`xml:id`は空でした。バージョン1.2はクラスター全体で形を数え、ソースレコードの見解が一致する形を残します。残りは`<persName type="variant">`として、頻度の高い順に付いてきます。日付は正規化され（`1572-08-00`は`1572-08`に）、テキストと`@when`属性とで二度出力されます。ファイル中の日付を扱う処理が実際に読むのは、この属性のほうです。性別と説明は、VIAFが公開している場合に現れます。

私がいちばん欲しかった部分です。VIAFが`schema:sameAs`と自前のソースIDを通じてリンクしている識別子は、すべて`<idno>`として書き出されます――BnF、GND、米国議会図書館、SUDOC、Wikidata、ISNI、BNE、LIBRIS、NDL。番号一つを入れれば、目録九つが出てきます。人物誌にとってこれは、名前の一覧と、典拠データの網の目に結ばれた一つの結節点との違いです。

```xml
<person xml:id="pers-teligny-c">
  <persName>Charles de Téligny</persName>
  <birth when="1535">1535</birth>
  <death when="1572-08-24">1572-08-24</death>
  <sex value="M">M</sex>
  <idno type="VIAF">314802260</idno>
  <idno type="BNF">16133360</idno>
  <idno type="Wikidata">Q1868249</idno>
  <idno type="ISNI">0000000071126808</idno>
</person>
```

## スニペットから人物誌へ

XMLを端末に印字するだけなら、人物が一人のうちはそれで済みます。校訂版には何百人もいます。persNamerは今や複数のVIAF番号を一度に受け取り、リクエストの合間には行儀よく間を置き、取得したものはキャッシュし、そして`--merge`を付ければ、新しいエントリを既存のTEIファイルの`<listPerson>`に直接挿入します。すでにあるレコードはVIAF番号で見分けて、その`xml:id`を使い回します。新しいIDはファイルと照合し、衝突するようなら接尾辞（`-2`、`-3`）を付けます。ファイルはインデントを整え直され、その前に`.bak`のコピーが書き出されます。

```bash
persnamer --merge edition.xml 314802260 36925746
```

知っておくべき変更が一つ。姓の前置小辞は既定でIDから落とすようになったので、シャルル・ド・テリニーは`pers-deteligny-c`ではなく`pers-teligny-c`になります。プロジェクトが旧来の形で落ち着いているなら、`--keep-particle`で元に戻せます。名前にまったく依存したくないというのであれば、`--id-format viaf`で`pers-viaf-314802260`が得られます。

## こまごまとした整備

スクリプトはパッケージになり、`persnamer`コマンドが付きました。`uv tool install`か`pipx`で一行で導入できます（インストールせず一度だけ走らせるなら`uvx`で）。26本のテストは記録済みのVIAF応答に対して走るので、テストスイートにネットワークは要りません。CIはPython 3.9から3.13までで回し、出力はTEI P5に照らして検証されます。ライセンスはこれまでどおりApache 2.0です。

依然としてできないのは、その人がどこで生まれ、何を生業にしていたかを教えることです。VIAFのクラスターRDFには場所も職業も載っていません。リンク先のBnFとGNDのレコードには載っています――そして今や、その番号は手元にあります。

コードとドキュメントは[GitHub](https://github.com/Pantagrueliste/persNamer)にあります。

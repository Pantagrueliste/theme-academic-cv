# 問題
歴史的なアーカイブは、うんざりするほど乱雑なことがあります。[フィレンツェ国立文書館](https://www.archiviodistato.firenze.it/asfi/home)の*Mediceo del Principato*はその好例です。実際、目録が作成されているのはそのごく一部にすぎず、多くの文書は明白な理由もなく6,500巻以上に散在しています。さらに事態を複雑にしているのは、文書館では閲覧できる巻（現地で*filze*と呼ばれるもの）の数が限られていることです。通常時の上限は1日4*filze*です。しかしパンデミックの時期には、その数は2週間に4冊にまで減りました。詳細な目録がない中で、文書館の相当な規模は、探している文書を素早く見つけるための戦略を研究者に強いることになります。

# 解決策
偶然に賭ける人もいれば、年代、受取人、著者、文書群の由来、言語などを手がかりに、根拠のある推測を試みる人もいるでしょう。しかし、これらすべての変数を同時に*眺める*ことで、アーカイブの構造について予期しないパターンが明らかになり、私たちの推測が改善されるかもしれません。私の経験では、研究者が通常スプレッドシートに集めるメタデータは、グラフ化するとアーカイブにおける状況認識を大幅に高めることができます。

# 実験
私の現在の研究は、16世紀のあるスパイの書簡に焦点を当てています。彼の手紙は数百の*filze*に散らばっています。それらは異なる身元のもとで、異なる、ときには予想外の宛先へ、異なる場所から書かれています。目当ての手紙を含んでいる可能性がより高い*filze*を見つけるために、私はダッシュボード、すなわちインタラクティブなデータ可視化ウェブアプリケーション（[Plotly Dash](https://plotly.com/dash/)）を構築しました。これは、地理的・年代的情報を含むあらゆる種類のデータを、文書群の階層図（[サンバースト](https://datavizproject.com/data-type/sunburst-diagram/)）と結びつけるものです。ダッシュボードは、すでに何が見つかっているか、それがどれほどの割合を占めるかを一目で教えてくれ、新しい手紙をどこで探せそうかについての大まかな見当を与えてくれます。さらに、特定の変数をクリックすると、すべての図が更新されて特定の相関関係を表示します。

## tei-mcp: एआई एजेंटों के लिए TEI P5

tei-mcp एक ओपन-सोर्स [MCP](https://modelcontextprotocol.io) सर्वर है, जो एआई कोडिंग असिस्टेंटों को [TEI P5](https://tei-c.org/guidelines/) विनिर्देश तक सीधी पहुँच देता है। प्रशिक्षण-डेटा की धुँधली याद के भरोसे रहने के बजाय – जिससे अक्सर देखने में ठीक-ठाक पर ग़लत मार्कअप निकलता है – एआई विनिर्देश से सीधे, उसी वक़्त पूछ सकता है।

## विशेषताएँ

सर्वर TEI P5 के ODD को पार्स करता है और 16 उपकरण उपलब्ध कराता है:

- किसी भी एलिमेंट, क्लास, मैक्रो या मॉड्यूल की **खोज** नाम से – बड़े-छोटे अक्षर का भेद किए बिना, और टाइपिंग की ग़लती पर सुझाव के साथ
- पूरी TEI क्लास-श्रेणी में **एट्रिब्यूट का निर्धारण** (स्थानीय + विरासत में मिले)
- क्लास और मैक्रो को खोलते हुए **कंटेंट मॉडल का विस्तार** संरचित वृक्ष के रूप में
- **नेस्टिंग की जाँच** – सीधा अभिभावक-संतान संबंध या पथ के साथ पुनरावर्ती पहुँच
- TEI P5 के विरुद्ध **दस्तावेज़ की वैधता-जाँच**: कंटेंट मॉडल, एट्रिब्यूट, बंद मान-सूचियाँ, संदर्भों की अखंडता और अप्रचलन की चेतावनियाँ
- क्रमिक संपादन के लिए **एकल एलिमेंट की वैधता-जाँच**
- स्कीमा को किसी परियोजना-विशेष उपसमुच्चय तक सीमित करने के लिए **ODD अनुकूलन लोड करना**
- रेगुलर एक्सप्रेशन से सभी प्रकार की इकाइयों में **खोज**

## इंस्टॉलेशन

```bash
pip install tei-mcp
```

या सीधे चलाइए:

```bash
uvx tei-mcp
```

## उपयोग

किसी भी MCP-संगत क्लाइंट (Claude, Cursor, Windsurf आदि) में जोड़िए:

```json
{
  "mcpServers": {
    "tei": {
      "command": "uvx",
      "args": ["tei-mcp"]
    }
  }
}
```

स्रोत कोड और दस्तावेज़ीकरण [GitHub रिपॉज़िटरी](https://github.com/Pantagrueliste/tei-mcp) पर उपलब्ध हैं।

## tei-mcp: TEI P5 для ИИ-агентов

tei-mcp — [MCP](https://modelcontextprotocol.io)-сервер с открытым исходным кодом, дающий ИИ-ассистентам для программирования прямой доступ к спецификации [TEI P5](https://tei-c.org/guidelines/). Вместо того чтобы полагаться на заученные обучающие данные — что часто даёт правдоподобную, но неверную разметку, — ИИ может обращаться к спецификации в реальном времени.

## Возможности

Сервер разбирает TEI P5 ODD и предоставляет 16 инструментов:

- **Поиск** любого элемента, класса, макроса или модуля по имени без учёта регистра и с подсказками при опечатках
- **Разрешение атрибутов** по всей иерархии классов TEI (локальные + унаследованные)
- **Развёртывание моделей содержимого** в структурированные деревья с разрешением классов и макросов
- **Проверка вложенности** — прямая связь «родитель — потомок» или рекурсивная достижимость с отслеживанием пути
- **Валидация документов** по TEI P5: модели содержимого, атрибуты, закрытые списки значений, целостность ссылок и предупреждения об устаревших элементах
- **Валидация отдельных элементов** для пошагового редактирования
- **Загрузка ODD-настроек**, ограничивающих схему подмножеством, принятым в проекте
- **Поиск по регулярным выражениям** среди всех типов сущностей

## Установка

```bash
pip install tei-mcp
```

Или запустите напрямую:

```bash
uvx tei-mcp
```

## Использование

Добавьте в любой MCP-совместимый клиент (Claude, Cursor, Windsurf и т. д.):

```json
{
  "mcpServers": {
    "tei": {
      "command": "uvx",
      "args": ["tei-mcp"]
    }
  }
}
```

Исходный код и документация — в [репозитории на GitHub](https://github.com/Pantagrueliste/tei-mcp).

## tei-mcp: استاندارد TEI P5 برای عامل‌های هوش مصنوعی

tei-mcp سرور [MCP](https://modelcontextprotocol.io) متن‌بازی است که به دستیارهای برنامه‌نویسی هوش مصنوعی دسترسی مستقیم به مشخصات [TEI P5](https://tei-c.org/guidelines/) می‌دهد. هوش مصنوعی به جای تکیه بر داده‌های آموزشی به‌خاطرسپرده — که اغلب نشانه‌گذاری موجه‌نما اما نادرست تولید می‌کند — می‌تواند مشخصات را در لحظه پرس‌وجو کند.

## امکانات

سرور ODD استاندارد TEI P5 را تجزیه می‌کند و 16 ابزار در اختیار می‌گذارد:

- **جست‌وجوی** هر عنصر، کلاس، ماکرو یا پیمانه با نام، بدون حساسیت به حروف بزرگ و کوچک و با پیشنهاد اصلاح غلط‌های تایپی
- **تعیین صفت‌ها** در سراسر سلسله‌مراتب کلاس‌های TEI (محلی + به‌ارث‌رسیده)
- **بسط مدل‌های محتوا** به درخت‌های ساخت‌یافته با تعیین کلاس‌ها و ماکروها
- **اعتبارسنجی تودرتویی** — رابطهٔ مستقیم والد–فرزند یا دسترس‌پذیری بازگشتی با ردیابی مسیر
- **اعتبارسنجی اسناد** در برابر TEI P5: مدل‌های محتوا، صفت‌ها، فهرست‌های بستهٔ مقادیر، یکپارچگی ارجاع‌ها و هشدارهای منسوخ‌شدگی
- **اعتبارسنجی تک‌عنصرها** برای گردش‌های کاری ویرایش تدریجی
- **بارگذاری سفارشی‌سازی‌های ODD** برای محدود کردن شِما به زیرمجموعهٔ خاص یک پروژه
- **جست‌وجو** در همهٔ انواع موجودیت‌ها با الگوهای regex

## نصب

```bash
pip install tei-mcp
```

یا اجرای مستقیم با:

```bash
uvx tei-mcp
```

## کاربرد

به هر کلاینت سازگار با MCP (Claude، Cursor، Windsurf و جز آن) بیفزایید:

```json
{
  "mcpServers": {
    "tei": {
      "command": "uvx",
      "args": ["tei-mcp"]
    }
  }
}
```

کد منبع و مستندات را در [مخزن GitHub](https://github.com/Pantagrueliste/tei-mcp) بیابید.

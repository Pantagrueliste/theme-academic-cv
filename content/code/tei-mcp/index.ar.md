## tei-mcp: مواصفة TEI P5 في متناول وكلاء الذكاء الاصطناعي

tei-mcp خادم [MCP](https://modelcontextprotocol.io) مفتوح المصدر يفتح لمساعدي البرمجة بالذكاء الاصطناعي بابًا مباشرًا إلى مواصفة [TEI P5](https://tei-c.org/guidelines/). فبدل أن يتكل النموذج على ما حفظه من بيانات التدريب — وكثيرًا ما يُخرج ترميزًا معقول المظهر باطل الجوهر — يستطيع أن يستفتي المواصفة نفسها في الحين.

## الميزات

يحلّل الخادم ملف ODD الخاص بـTEI P5 ويتيح 16 أداة:

- **البحث** عن أي عنصر أو صنف أو ماكرو أو وحدة (module) بالاسم، مع مطابقة لا تفرّق بين حالتي الأحرف واقتراحات لتصويب الأخطاء الإملائية
- **حل السمات** عبر التسلسل الهرمي الكامل لأصناف TEI (المحلية والموروثة معًا)
- **بسط نماذج المحتوى** في أشجار مهيكلة مع حل الأصناف والماكروات
- **التحقق من التداخل** — علاقة الأصل بالفرع مباشرةً، أو إمكانية البلوغ تعاوديًّا مع تتبع المسار
- **التحقق من صحة الوثائق** وفق TEI P5: نماذج المحتوى، والسمات، وقوائم القيم المغلقة، وسلامة الإحالات، وتحذيرات الإهمال (deprecation)
- **التحقق من صحة عنصر مفرد** لمن يحرّر خطوةً خطوة
- **تحميل تخصيصات ODD** لحصر المخطط في مجموعة فرعية خاصة بمشروع بعينه
- **البحث** في أنواع الكيانات كافة بالتعابير النمطية

## التثبيت

```bash
pip install tei-mcp
```

أو شغّلوه مباشرةً بـ:

```bash
uvx tei-mcp
```

## الاستخدام

أضيفوه إلى أي عميل متوافق مع MCP (Claude وCursor وWindsurf وغيرها):

```json
{
  "mcpServers": {
    "tei": {
      "command": "uvx",
      "args": ["tei-mcp"]
    }
  }
}
```

تجدون الشيفرة المصدرية والتوثيق في [مستودع GitHub](https://github.com/Pantagrueliste/tei-mcp).

## tei-mcp: مواصفة TEI P5 لوكلاء الذكاء الاصطناعي

tei-mcp خادم [MCP](https://modelcontextprotocol.io) مفتوح المصدر يمنح مساعدي البرمجة بالذكاء الاصطناعي وصولًا مباشرًا إلى مواصفة [TEI P5](https://tei-c.org/guidelines/). فبدلًا من الاعتماد على بيانات تدريب محفوظة — وهو ما ينتج غالبًا ترميزًا معقول المظهر لكنه غير صحيح — يستطيع الذكاء الاصطناعي الاستعلام من المواصفة في الوقت الفعلي.

## الميزات

يحلّل الخادم ملف ODD الخاص بـTEI P5 ويعرض 16 أداة:

- **البحث** عن أي عنصر أو صنف أو ماكرو أو وحدة (module) بالاسم، مع مطابقة غير حساسة لحالة الأحرف واقتراحات لتصحيح الأخطاء الإملائية
- **حل السمات** عبر التسلسل الهرمي الكامل لأصناف TEI (المحلية + الموروثة)
- **توسيع نماذج المحتوى** إلى أشجار مهيكلة مع حل الأصناف والماكروات
- **التحقق من التداخل** — علاقة الأصل والفرع المباشرة أو إمكانية الوصول التعاودية مع تتبع المسار
- **التحقق من صحة الوثائق** مقابل TEI P5: نماذج المحتوى، والسمات، وقوائم القيم المغلقة، وسلامة المراجع، وتحذيرات الإهمال (deprecation)
- **التحقق من صحة عناصر مفردة** لسير عمل التحرير التدريجي
- **تحميل تخصيصات ODD** لتقييد المخطط بمجموعة فرعية خاصة بمشروع معيّن
- **البحث** عبر جميع أنواع الكيانات بالتعابير النمطية

## التثبيت

```bash
pip install tei-mcp
```

أو التشغيل المباشر بـ:

```bash
uvx tei-mcp
```

## الاستخدام

أضيفوه إلى أي عميل متوافق مع MCP (Claude وCursor وWindsurf، إلخ):

```json
{
  "mcpServers": {
    "tei": {
      "command": "uvx",
      "args": ["tei-mcp"]
    }
  }
}
```

تجدون الشيفرة المصدرية والتوثيق في [مستودع GitHub](https://github.com/Pantagrueliste/tei-mcp).
